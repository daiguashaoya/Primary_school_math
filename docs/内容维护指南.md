# 内容维护指南

## 1. 修改已有备课

当前内容源文件是：

- `备课资料/01_答案速查.md`
- `备课资料/02_逐题解析与教学方法.md`

修改 Markdown 后，如果内容已经更新，将 `content/catalog.json` 中这一项的 `updated` 改为真实更新日期，然后运行：

```powershell
python scripts/build_site.py
```

打开对应阅读页，核对算式、图形、目录跳转与图片显示。不要直接修改自动生成的 `index.html` 或资料阅读页；下一次生成时会覆盖。

原有的 `备课资料/00_答案与讲解_可打印.html` 和 PDF 是独立版本。需要同步分发新版 PDF 时，应另外更新该文件；只改 Markdown 不会自动改写 PDF。

## 2. 新增一节课堂内容

### 第一步：编写源文件

例如新建 `content/lessons/decimal-division.md`，参考 `content/章节模板.md`，写入真实的课堂内容。

建议用这些层级：

```markdown
# 小数除法

本节学习目标与已学基础。

## 一、核心知识

## 二、典型例题

### 例1：题目

**解答：**

**考点与方法：**

**易错点：**

## 三、课堂练习与答案

## 四、课后小结
```

图片路径相对于这份 Markdown 所在文件夹填写，例如 `images/example.png`。不要填写某台电脑的 `D:/...` 或 `C:/...` 绝对路径。

### 第二步：登记目录

在 `content/catalog.json` 的 `entries` 数组中添加一项，例如：

```json
{
  "id": "decimal-division",
  "category": "chapters",
  "title": "小数除法：算理与实际应用",
  "summary": "填写这一节实际包含的内容。",
  "grade": "五年级",
  "updated": "2026-11-10",
  "topics": ["小数计算"],
  "keywords": ["小数除法", "商不变的性质"],
  "figures": 0,
  "sections": [
    {
      "id": "lesson",
      "title": "课堂内容",
      "source": "content/lessons/decimal-division.md"
    }
  ],
  "attachments": []
}
```

上面只是登记格式示例，日期、标题、考点要按实际内容填写。将 `category` 设为 `preparation`，就会进入备课栏目；设为 `chapters`，则进入课堂章节栏目。

关键字段：

| 字段 | 说明 |
| --- | --- |
| `id` | 全站唯一，用英文小写和连字符；发布后尽量保持不变，避免旧链接失效 |
| `category` | `preparation` 或 `chapters` |
| `updated` | 实际更新日期，格式为 `YYYY-MM-DD`；用于排序 |
| `topics` | 显示为标签，也用于栏目筛选 |
| `keywords` | 用于搜索，可以包含题型、方法与术语 |
| `figures` | 本份资料的不同图解数量，没有图片填0 |
| `sections` | 一份资料可以有一个或多个部分，如“答案速查”“逐题讲解” |
| `source` | 从仓库根目录出发的 Markdown 路径 |
| `attachments` | 可选原卷、PDF或旧版HTML，`kind` 分别为 `image`、`pdf`、`html` |

### 第三步：生成并提交

```powershell
python scripts/build_site.py
python -m http.server 8000
```

在浏览器检查新章节，再停止预览服务并提交：

```powershell
git add content chapters preparation index.html
git commit -m "Add a new math lesson"
git push
```

如果同时新增了图片、PDF或其他资料目录，也要把这些文件加入提交。Pages 开启后会随 `main` 更新。

## 3. 页面与样式维护

- `assets/site.css`：站点布局、手机适配与打印样式。
- `assets/site.js`：手机导航、资料筛选、搜索与阅读进度。
- `scripts/build_site.py`：HTML模板与 Markdown 转换器。
- `assets/math-notebook.svg`：首页的数学笔记插图。

Markdown 转换器支持标题、段落、粗体、行内代码、代码块、表格、列表、链接、图片和分隔线。当前算式使用普通数学字符，不依赖在线公式库。

保持站内链接为相对路径，不使用以 `/assets/` 开头的站点根路径，避免在 GitHub Pages 项目站下失效。
